O **Células** é um aplicativo Flutter desenvolvido para facilitar a organização, participação e interação em comunidades cristãs e células (reuniões nos lares). O design foi inspirado por temas espirituais, utilizando uma paleta de cores **Vinho (Sangue de Cristo)** e **Bege (Papel de Bíblia Antiga)**. ## 🚀 Como Começar

### Pré-requisitos
*   [Flutter SDK](https://docs.flutter.dev/get-started/install) instalado.
*   [Dart SDK](https://dart.dev/get-started/sdk) instalado.
*   Um emulador (iOS/Android) ou dispositivo físico conectado.

### Instalação
1.  Clone este repositório:
    ```bash
    git clone https://github.com/joelsantos19/celulacrista.git
    ```
2.  Entre na pasta do projeto:
    ```bash
    cd celulacrista
    ```
3.  Instale as dependências:
    ```bash
    flutter pub get
    ```
4.  Execute o aplicativo:
    ```bash
    flutter run
    ```

## ✨ Funcionalidades (MVP)

*   **Tela de Login**: Identidade visual forte e espiritual.
*   **Home/Dashboard**: 
    *   **Palavra do Dia**: Versículos dinâmicos com meditação.
    *   **Destaque "Encontro com Cristo"**: Banner especial para eventos.
    *   **Navegação Lateral**: Swipe entre as abas principais.
*   **Células**: Encontre células próximas de você ou participe de reuniões online via links integrados.
*   **Cultura Cristã**: Catálogo de filmes, músicas (Rock Gospel - Oficina G3) e pregações (Série Peniel).
*   **Comunidade**: Mural de anúncios e um Mural Anônimo para compartilhamento de mensagens de fé.
*   **Igrejas**: Detalhes da **Igreja Paz das Nações**, avisos e pedidos de ajuda.

## 🎨 Identidade Visual
*   **Primária**: Vinho (`#800000`) - Simbolizando o sacrifício e o Sangue de Cristo.
*   **Fundo**: Bege (`#F5E6D3`) - Inspirado em páginas de Bíblias antigas e manuscritos.
*   **Acento**: Ouro (`#C5A059`) - Representando a glória e o sagrado.

## 🛠️ Tecnologias
*   Flutter & Dart.
*   Arquitetura organizada por Features para escalabilidade.
*   Dados Mock (Simulados) via `MockDataService`.
